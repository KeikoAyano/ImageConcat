# Image Concat

Android images concat<br>

## Get Start
Install the apk file in the release.<br>

### Samsung 
1. Go to "Setting and privacy" and turn off "Auto Blocker"<br>
2. click and Install apk installer<br>

## Features
- Concat Images<br>
- Add RecycleView && Images number limit (5)<br>
- Change the UI and logo (AI generated)<br>
